ls: lista archivos en un directorio.

cd: cambia de directorio.

pwd: muestra la ruta del directorio actual.

cp: copia archivos o directorios.

mv: mueve o renombra archivos.

rm: elimina archivos o directorios.

mkdir: crea nuevos directorios.

rmdir: elimina directorios vacíos.

find: busca archivos en el sistema.

locate: búsqueda rápida de archivos (usa una base de datos actualizable).

tree: muestra estructura de directorios en forma de árbol.

cat: muestra contenido de archivos.

less / more: permite navegar por archivos largos.

head / tail: muestra el principio o el final de un archivo.

nano, vim, vi: editores de texto en terminal.

touch: crea archivos vacíos o actualiza su fecha.

stat: muestra detalles de un archivo.

whoami: muestra el usuario actual.

id: muestra el UID, GID, y grupos.

adduser / useradd: crea un nuevo usuario.

passwd: cambia la contraseña de un usuario.

chown: cambia el propietario de un archivo.

chmod: cambia los permisos de un archivo.

su: cambia de usuario (switch user).

sudo: ejecuta comandos como superusuario.

ps: lista procesos.

top / htop: monitor de procesos en tiempo real.

kill: termina procesos.

killall: termina procesos por nombre.

nice / renice: cambia prioridad de procesos.

uptime: muestra cuánto tiempo lleva encendido el sistema.

free: muestra uso de memoria.

df: muestra espacio en disco.

du: muestra el tamaño de archivos/carpetas.

ip a: muestra interfaces y direcciones IP.

ping: verifica conectividad.

curl: descarga o interactúa con URLs.

wget: descarga archivos desde la web.

netstat / ss: muestra conexiones de red.

nmap: escanea puertos (necesita instalación).

hostname: muestra o cambia el nombre del host.

Debian/Ubuntu:

    apt update / apt upgrade

    apt install nombre-paquete

    dpkg -i paquete.deb

RHEL/CentOS:

    yum install / dnf install

Arch Linux:

    pacman -S / pacman -R

grep: busca patrones dentro de archivos.

awk: procesador de texto muy poderoso.

sed: editor de texto en línea de comandos.

cut, sort, uniq: manipulación de datos.

xargs: ejecuta comandos con argumentos de entrada.

tee: redirige y guarda salida estándar.

cron / crontab: automatización de tareas.

alias: crea atajos para comandos.
